# Daftar Tugas Kuliah

## 1. Deskripsi Proyek

Daftar Tugas Kuliah merupakan aplikasi berbasis web yang dibuat untuk membantu mahasiswa mencatat dan mengelola tugas perkuliahan. Aplikasi ini menyediakan fitur untuk menambahkan, mengedit, menghapus, dan mengubah status tugas.

## 2. Teknologi yang Digunakan

- HTML
- CSS
- TypeScript
- Vite

## 3. Git dan GitHub

Git digunakan untuk mengelola perubahan kode program melalui sistem version control. GitHub digunakan sebagai tempat penyimpanan repository secara online.

Dalam pengerjaan proyek ini, diterapkan beberapa proses Git dan GitHub, yaitu:

- Commit untuk menyimpan perubahan kode.
- Branch untuk mengembangkan fitur secara terpisah.
- Merge untuk menggabungkan perubahan antar-branch.
- Merge conflict untuk memahami dan menyelesaikan konflik kode.
- Pull Request (PR) untuk mengajukan penggabungan perubahan ke branch utama.
- Push dan pull untuk mengirim serta mengambil perubahan repository.

## 4. npm dan package.json

npm merupakan package manager yang digunakan untuk mengelola dependency proyek.

File `package.json` berisi informasi proyek, daftar dependency, dan script yang digunakan untuk menjalankan aplikasi.

Script yang digunakan:

- `npm run dev` untuk menjalankan development server.
- `npm run build` untuk membangun aplikasi.
- `npm run preview` untuk melihat hasil build.

## 5. TypeScript

TypeScript merupakan pengembangan dari JavaScript yang menyediakan sistem tipe data.

Dalam proyek ini diterapkan:

- Primitive types: string, number, dan boolean.
- Array untuk menyimpan kumpulan data.
- Interface untuk menentukan struktur objek.
- Type alias dan union type untuk mendefinisikan tipe data.
- Generic untuk membuat fungsi atau struktur kode yang fleksibel.

## 6. Vite

Vite digunakan sebagai development server dan build tool. Vite membantu proses pengembangan aplikasi serta menghasilkan file build yang siap digunakan untuk deployment.

## 7. Environment Variables

Environment variables digunakan untuk menyimpan konfigurasi aplikasi di luar kode utama.

File `.env.example` disediakan sebagai contoh konfigurasi, sedangkan file `.env` digunakan untuk konfigurasi lokal dan tidak diunggah ke repository.
